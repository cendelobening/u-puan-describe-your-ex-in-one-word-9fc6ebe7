My one-word verdict on an ex: **"Unsubscribed"**. It turns the ex into a mailing list you opted out of — no more updates, by your own choice, with one click. The whole breakup is inside the word: the endless unwanted messages, the final unsubscribe, the silence after. It is a verdict on the person, not a description of what they did, and anyone who has ever hit unsubscribe feels the truth in it instantly.

## Run it

```sh
python3 main.py
```

The program writes exactly one word, `Unsubscribed`, to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`), with nothing else attached.
